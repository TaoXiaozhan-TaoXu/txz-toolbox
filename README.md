# 陶小站工具箱

> 一个干净的 Windows 小工具合集 —— 双击安装，打开就能用，不用登录、没有广告。

---

## ✨ 这是什么

陶小站工具箱把日常用得到的小功能收进了一个清爽的窗口里：

- 左边按分类挑选工具，右边卡片式列表，点开即用
- 图片、看图、查询、音视频、短视频，几大类一站备齐
- 所有处理都在本地完成，不收集任何个人信息

## 🧰 内置工具

| 分类 | 工具 | 说明 |
| --- | --- | --- |
| 图片工具 | PNG 转 JPG / JPG 转 PNG | 本地上传或粘贴链接，几秒出结果 |
| 看看图片 | 随机图片、二次元图墙 | 随机看图，分类切换，点开可放大 |
| 查询工具 | 星座运势 | 今日 / 本周 / 本月运势与幸运色 |
| 音视频 | MP4 转 MP3 | 粘贴视频链接，提取音频并试听保存 |
| 短视频 | 随机短视频 | 多个片源，自建播放条，连续播放 |

> 更多工具在持续打磨中，每次启动会自动检查更新。

## 🚀 下载与安装

> 官方下载页：**https://dl.taoxz.cn** （自动显示最新版本、更新内容和校验值）


1. 打开右侧 **Releases**，下载最新版的安装包
2. 双击安装，装完会自动启动
3. 双击桌面快捷方式即可使用
4. 卸载：Windows 设置 → 应用 → 陶小站工具箱 → 卸载

## 🔄 更新

- 启动时自动检查新版本
- 有新版本会弹窗提示，可自行选择是否更新
- 侧边栏也会显示更新入口，随时可以查看更新内容
